# Clases de Español

Proyecto independiente (encargos ESP-01 y ESP-02). No forma parte de Gente México.

- `index.html`: micrositio del alumno, autocontenido, en inglés. Lecciones 1 y 2, examen de colocación, tarea, laboratorio de sonidos y conversación.
- Sitio publicado con GitHub Pages desde `main`.
- **Registro de actividad:** el sitio envía eventos (respuestas, puntajes, pasos, tarea; nunca audio) al formulario de Google «Clases de Español · Progreso», que alimenta la hoja «Clases de Español · Progreso (Respuestas)». Configuración en `LOG_CONFIG` dentro de `index.html`.
- **Asignar la siguiente lección:** cambiar `ASSIGNED` y `HOMEWORK` en `index.html`.
